Key material

Fixed demo seeds (same as the WOTS posts). Leaves are real SHRINCS WOTS-TW public keys compressed with T_sl; parents use tweakable H.

WOTS gives you a one-time signature which breaks if used to sign more than one message. XMSS (eXtended Merkle Signature Scheme) is how you turn many WOTS keys into a single many-time verifying key. The demo above builds a small tree (h=3, eight WOTS leaves) so every node fits on screen.
